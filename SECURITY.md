# Security Policy

## Versões suportadas

O Nexo CRM é uma demonstração em desenvolvimento. Apenas a branch `main`
recebe correções de segurança.

## Reportando uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades. Envie um relato privado para
o mantenedor do repositório com:

- descrição do problema e impacto;
- passos de reprodução;
- versão ou commit afetado;
- sugestão de correção, se houver.

Você receberá uma confirmação de recebimento. Divulgaremos a correção de forma
coordenada.

## Escopo

Estão no escopo: API GraphQL/REST, worker, front-end, infraestrutura local e
supply chain. Não use dados reais, credenciais reais ou endpoints de produção
deste projeto para testes.

Consulte [`docs/security.md`](docs/security.md) para o mapeamento de controles
e riscos pendentes.
